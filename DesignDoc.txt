## 🏷️ Project Overview

**Ghosted.AI** is a web application that analyzes exported chat conversations to detect emotional trends, interest levels, and ghosting patterns — powered by AI and behavioral metrics. It transforms raw chat data into a brutally honest, slightly sarcastic analytical report that tells users what they probably already suspected.

---

## 🎯 Goals & Philosophy

### Core Objective

Build a fast, engaging web app that:

- Parses and analyzes chat conversations from exported files
- Detects interest levels and engagement trends over time
- Identifies early and late-stage ghosting signals
- Delivers an AI-generated summary that is honest, data-backed, and darkly funny

### Product Philosophy

> *If it feels too safe → it's boring. If it feels too harsh → users won't return.*

The product must balance honesty with humor. Every insight should feel like a smart friend telling you the truth — not a therapist, not a bully. The UI should match: clean, dark, and slightly uncomfortable in the best way.

## 🎨 Design Language

### Visual Aesthetic

Ghosted.AI's design is inspired by modern data dashboards — think Bloomberg Terminal meets dating app — with a dark, cinematic feel. The UI should feel premium and analytical, not playful or bubbly.

**Core Aesthetic Pillars:**

- **Dark & moody** — Deep navy/black backgrounds, glass morphism cards
- **Data-forward** — Everything feels like a live analytics dashboard
- **Subtle sarcasm** — Microcopy and labels carry the personality; the UI stays clean
- **Cinematic depth** — Layered backgrounds, glowing accents, subtle particle or aurora effects

### Layout Principles

- Max content width: `1280px`, centered
- Consistent `24px` grid padding on all sides
- Cards use `border-radius: 16px` with `backdrop-filter: blur(12px)`
- Generous whitespace — never crowded
- Responsive: Mobile-first, scales up to desktop

## ✨ Animations & Transitions

**Libraries:**

- [Motion.dev](https://motion.dev/) — For component animations, scroll effects, layout transitions
- [21st.dev](https://21st.dev/home) — For pre-built animated UI primitives and micro-interactions

### Motion Principles

- **Purposeful** — Every animation communicates something (loading, state change, reveal)
- **Fast** — Default duration: `200–400ms`. Nothing lingers.
- **Eased** — Use `ease-out` for entrances, `ease-in` for exits
- **Non-blocking** — Animations never prevent interaction

### Animation Tokens

| Token | Value | Use |
|---|---|---|
| `--duration-fast` | `150ms` | Hover states, button presses |
| `--duration-base` | `300ms` | Card reveals, state transitions |
| `--duration-slow` | `600ms` | Page transitions, chart draws |
| `--easing-default` | `cubic-bezier(0.16, 1, 0.3, 1)` | General entrance |
| `--easing-bounce` | `cubic-bezier(0.34, 1.56, 0.64, 1)` | Score counter pop |

### Key Animations (Motion.dev)

```javascript
// Page section entrance
animate(element, 
  { opacity: [0, 1], y: [24, 0] }, 
  { duration: 0.4, easing: [0.16, 1, 0.3, 1] }
)

// Interest Score counter (0 → final value)
animate(scoreEl, 
  { innerText: [0, finalScore] }, 
  { duration: 1.2, easing: 'ease-out' }
)

// Card hover lift
animate(card, 
  { y: -4, boxShadow: '0 8px 40px rgba(0,229,192,0.15)' }, 
  { duration: 0.2 }
)

// Drag-over pulse on upload zone
animate(dropzone, 
  { scale: [1, 1.02, 1] }, 
  { duration: 0.4, repeat: Infinity }
)
```

### Transition Spec Per Interaction

| Interaction | Animation |
|---|---|
| Page load | Staggered fade-up of sections (60ms delay between each) |
| File drag-over | Drop zone scales up + border pulses teal |
| File upload progress | Animated progress bar fills left to right |
| Analysis loading | Brain icon pulses + skeleton loaders on cards |
| Charts reveal | Lines/bars animate in from bottom on scroll enter |
| Score reveal | Number counts up dramatically, then settles |
| Red flag appear | Slide in from right with red glow flash |
| CTA button hover | Slight scale up + glow intensifies |

## ⚙️ Core Features Spec

### 1. Chat Upload & Parsing

**Accepted Format:** WhatsApp `.txt` export

**Parsing Logic:**

```
Pattern: [DD/MM/YYYY, HH:MM:SS] Sender: Message
Output: Array of { sender, timestamp, message, wordCount }
```

**Validations:**
- File must be `.txt`
- Max size: 5MB
- Minimum: 20 messages to produce meaningful analysis
- Handle malformed lines gracefully (skip and flag)

---

### 2. Conversation Metrics Engine

| Metric | Calculation |
|---|---|
| **Response Time** | Timestamp delta between consecutive messages of alternating senders |
| **Response Time Trend** | Rolling average over time — detect if getting slower |
| **Message Length** | Word count per message, averaged per sender per week |
| **Initiation Ratio** | Count of conversation starts per sender / total starts |
| **Emoji Usage** | Regex match on emoji unicode ranges per sender |
| **Laughter Signals** | Match: `lol`, `lmao`, `haha`, `hehe`, `💀`, `😂` per sender |
| **Ghosting Signals** | Response gaps > 24hrs, trailing off message length, initiation imbalance > 70% |

---

### 3. AI Analysis Engine

**Model:** OpenAI GPT-4o (or GPT-4-turbo)

**System Prompt Tone:** Honest, direct, slightly sarcastic. Like a very smart friend who's seen this pattern before.

**Input to AI:** Computed metrics JSON

**Required Output (strict JSON):**

```json
{
  "interest_score": 72,
  "more_invested": "User",
  "ghosting_signs": [
    "Response time increased 3x in the last 2 weeks",
    "They initiate only 18% of conversations"
  ],
  "summary": "You text first. They reply eventually. Classic situationship energy."
}
```

**Prompt Engineering Notes:**
- Instruct model to respond ONLY in the JSON schema above
- Include computed metrics in user message
- Validate JSON on response before rendering
- Fallback: if parse fails, retry once then show generic error

## 🔒 Constraints & Edge Cases

| Constraint | Handling |
|---|---|
| File size > 5MB | Reject at upload with clear error message |
| Malformed chat lines | Skip silently, count skipped lines, warn user if > 20% |
| < 20 messages | Warn user: "Not enough data for a meaningful roast" |
| AI API failure | Retry once, then show metrics-only view with "AI insights unavailable" |
| Group chats | Detect and warn: "Ghosted.AI works best with 1-on-1 conversations" |
| Non-WhatsApp format | Show format guide with example of correct format |
| User consent | Explicit privacy notice before upload; no data persistence |

---

## 🚫 Non-Goals (MVP)

- No user authentication or accounts
- No real-time chat or live monitoring
- No social features (following, comparing with friends)
- No custom ML model training
- No multi-platform import (iMessage, Telegram) in v1
- No backend database storage
