# 🧠 Ghosted.AI — Product Requirements Document (PRD)

## 🏷️ Overview

**Product Name:** Ghosted.AI
**Tagline:** Turning emotional damage into analytics

Ghosted.AI is a web application that analyzes chat conversations to detect emotional trends, interest levels, and ghosting patterns using AI and behavioral metrics.

---

## 🎯 Objective

Build a fast, engaging web app that:

* Analyzes chat conversations
* Detects interest levels and engagement trends
* Identifies signs of ghosting
* Provides a brutally honest AI-generated summary

---

## 👤 Target Users

* Gen Z / students
* Dating app users
* Overthinkers analyzing chats
* Anyone who has ever been ghosted

---

## 🧩 Core Features

### 1. Chat Upload

* Upload exported chat files (.txt, e.g. WhatsApp)
* Parse chat into structured format:

  * Sender
  * Timestamp
  * Message

---

### 2. Conversation Metrics Engine

#### Metrics Computed:

* **Response Time**

  * Average reply delay per participant
  * Trend over time

* **Message Length**

  * Average words per message
  * Detection of decreasing engagement

* **Initiation Ratio**

  * Who starts conversations more often

* **Engagement Signals**

  * Emoji usage
  * Laughter indicators (lol, haha, etc.)

---

### 3. AI Analysis Engine

Uses OpenAI API to generate insights.

#### Output:

* Interest Score (0–100)
* More Invested Person
* Ghosting Indicators
* Summary (honest, slightly sarcastic tone)

#### Output Format (Strict JSON):

```json
{
  "interest_score": number,
  "more_invested": "User | Other",
  "ghosting_signs": [],
  "summary": "string"
}
```

---

### 4. Visualization Dashboard

#### Display:

* Response Time Graph
* Message Length Trend
* Initiation Ratio

#### AI Insight Card:

* Interest Score
* Summary
* Key Red Flags

---

### 5. Results Output

User receives:

* Clear verdict
* Visual analytics
* AI-generated summary

## 🔒 Constraints

* Do not store chats without user consent
* Limit file size (e.g., 5MB max)
* Handle malformed chat formats gracefully

---

## 🚫 Non-Goals (MVP)

* No authentication
* No real-time chat
* No social features
* No custom ML model training

---

## ⚡ Product Philosophy

The product must:

* Be fast
* Be insightful
* Be slightly uncomfortable (truth hits hard)

If it feels too safe → it’s boring
If it feels too harsh → users won’t return

Balance honesty with humor.
